# Flowcast

Flowcast is church presentation software for scripture. This repository holds the downloads of Flowcast. The source code is private.

## Download

Open the [latest release](https://github.com/ephraimduncan/flowcast-releases/releases/latest), then download the file for your computer:

- Windows: `flowcast-<version>-setup.exe`. The installer has no code signature, so Windows SmartScreen shows a warning. Click **More info**, then click **Run anyway**.
- Mac with Apple silicon: `flowcast-<version>.dmg`.

## Update

Click **Check for Updates…** in the Flowcast menu on a Mac, or in the Help menu on Windows. On Windows, Flowcast downloads and installs the update. On a Mac, Flowcast opens the release page, and you download and install the new version.
